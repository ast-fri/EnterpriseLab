# OwnCloud Pre-filled Data

Place your OwnCloud files and folders in this directory.

## Directory Structure

This directory represents the admin user's home directory in OwnCloud.

```
owncloud_data/
├── README.md                    ← This file (will be copied to OwnCloud)
├── files/                       ← Regular files folder
│   ├── Documents/
│   │   ├── report.pdf
│   │   └── presentation.pptx
│   ├── Images/
│   │   └── logo.png
│   └── Spreadsheets/
│       └── data.xlsx
└── cache/                       ← OwnCloud cache (optional)
```

## How to Populate

### Option 1: Copy from Running Container

```bash
# From Arena/apps/ directory
./export_data_from_running_containers.sh

# Or manually:
docker cp owncloud:/mnt/data/admin ./owncloud/owncloud_data/
```

### Option 2: Manual Setup

Create the structure you want:

```bash
cd owncloud/owncloud_data/

# Create folders
mkdir -p files/Documents
mkdir -p files/Images
mkdir -p files/Spreadsheets

# Add files
cp ~/my-documents/*.pdf files/Documents/
cp ~/my-images/*.jpg files/Images/
cp ~/my-spreadsheets/*.xlsx files/Spreadsheets/
```

## During Build

The `init.sh` script will:
1. Start OwnCloud
2. Create admin user
3. Copy contents from `owncloud_data/` to `/mnt/data/admin/`
4. Run file scanner to index all files
5. Set proper permissions

## File Types Supported

OwnCloud supports all file types:
- Documents: `.pdf`, `.doc`, `.docx`, `.odt`
- Spreadsheets: `.xls`, `.xlsx`, `.ods`
- Presentations: `.ppt`, `.pptx`, `.odp`
- Images: `.jpg`, `.png`, `.gif`, `.svg`
- Videos: `.mp4`, `.avi`, `.mkv`
- Archives: `.zip`, `.tar.gz`
- Text: `.txt`, `.md`, `.csv`
- Code: `.py`, `.js`, `.html`, `.css`
- And more!

## Special Folders

### Files
Main folder for user files. This is what users see in OwnCloud web interface.

### Cache
OwnCloud's internal cache. Usually not needed to pre-populate.

### Thumbnails
Auto-generated by OwnCloud. Don't pre-populate.

## Permissions

The init script automatically sets permissions:
```bash
chmod -R 777 /mnt/data/admin
```

You don't need to worry about this when preparing files.

## Accessing Files

After building and starting the container:
1. Go to http://localhost:3001
2. Login as `admin` / `admin`
3. Your files will be visible in the Files app
4. All folders and files from `owncloud_data/` will be there!

## Tips

### Large Files
- Works fine, but increases image size
- Consider if 10GB+ files should be in the image or mounted later

### Organization
- Create a logical folder structure
- Group related files together
- Use descriptive folder names

### Sample Files
Create some sample data for testing:

```bash
cd owncloud/owncloud_data/files

# Create sample structure
mkdir -p Welcome/{Documents,Images}

# Add sample files
echo "# Welcome to OwnCloud" > Welcome/README.md
echo "This is a sample document" > Welcome/Documents/sample.txt
```

## Notes

- Everything in this directory will be in the final image
- Large files = larger Docker image
- File paths are preserved
- The build process will show file scanning progress
- OwnCloud will automatically generate thumbnails on first access
